# Arcade pictures

Put your own hero here as **`hero.png`** and The Labyrinth will use it instead of the built-in placeholder.

- The picture is a sprite sheet, **32 pixels wide and 64 pixels tall**: 2 columns by 4 rows of 16 x 16 frames.
- Rows, top to bottom: facing down, left, right, up.
- Columns: walking frame 1, walking frame 2.
- Leave the background see-through (transparent).

Step-by-step drawing instructions: [docs/arcade-art.md](../../docs/arcade-art.md).

If there is no `hero.png` here, the game quietly uses the placeholder hero.
